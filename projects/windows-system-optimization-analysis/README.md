# Windows Performance Troubleshooting

Diagnosed a slow Windows system and fixed it with PowerShell and built-in tools.

**Tools:** PowerShell, Task Manager, SFC, DISM

## Symptoms
High CPU and memory use, heavy startup apps, piled-up temp files.

## Actions
- Reviewed CPU and memory usage
- Disabled unneeded startup apps
- Cleared temp files and Recycle Bin
- Ran SFC and DISM repairs
- Flushed DNS and reset network components
- Rechecked the system afterwards

## Results
Faster response, less background load, freed disk space, integrity checks passed. Results apply to this system only.
